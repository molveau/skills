# Gallery Catalog - full per-site detail

Companion to `../SKILL.md`. Links and descriptions last checked 1 November 2026. Categories:
Full Sites · Landing Pages · SaaS · Navigation · CTAs · Motion · Branding · Components ·
Icons · Mobile/App.

## 1. Craftwork Curated - Websites
**URL:** https://craftwork.design/inspiration/websites · **Category:** Full Sites
- **Best for:** Hundreds of hand-picked complete websites + design patterns, sorted by
  industry/product (agencies, portfolios, Web3, AI, fintech, e-commerce).
- **Access:** Freemium. Free browsing; Pro (~$19/mo) opens up the broader library + downloadable
  assets (Figma/Framer templates, UI kits, icons, fonts).
- **Format:** Screenshot thumbnail cards linking to live sites.
- **Retrieval tip:** Toggle **Websites vs. Sections** tabs for whole-site vs section-level;
  filter by category (Services/Tech/Tools/Money/Apps) then subcategory; keyword search.

## 2. Landing Love
**URL:** https://www.landing.love/ · **Category:** Landing Pages
- **Best for:** Full landing pages **in motion** - ~2,000+ sites captured as full-page
  video recordings; strong for scroll/animation-heavy designs.
- **Access:** Open / free. No login.
- **Format:** Full-page **video recordings** + live links.
- **Retrieval tip:** Filter by Category (50+: Portfolio, Agency, SaaS, AI, 3D…), Style
  (Dark Mode, Gradient, Retro), Platform (Webflow, Framer, Wix Studio), or tech
  Collections (**GSAP, WebGL, ThreeJS**) - the tech collections are the standout for
  animation references.

## 3. Saaspo
**URL:** https://saaspo.com/ · **Category:** SaaS
- **Best for:** SaaS-specific web design - 1,400+ pages sliceable by **page type** (pricing,
  landing, features) and SaaS industry (AI / Dev / Design SaaS).
- **Access:** Open / free ("free forever"). No login. *(Homepage 403s to bots; open in a
  browser.)*
- **Format:** Screenshot gallery linking to live sites.
- **Retrieval tip:** Two power axes - `/page-types/...` (e.g. pricing-page examples) and
  `/industry/...` (e.g. ai-saas). Also filter by color and layout. Best source for one
  specific SaaS *page archetype*.

## 4. Navbar Gallery
**URL:** https://www.navbar.gallery/ · **Category:** Navigation
- **Best for:** Real-world navigation patterns for site/app headers and menus.
- **Access:** Open / free.
- **Format:** Screenshot/preview cards; visit source for live behavior.
- **Retrieval tip:** Filter by type - Sticky, Dropdown/Flyout, **Mega Menu**, Sidebar,
  Search Bar, Announcement Bar, Full-Screen Menu, Breadcrumbs. Card icons flag features.

## 5. CTA Gallery
**URL:** https://www.cta.gallery/ · **Category:** CTAs
- **Best for:** Conversion-focused call-to-action sections - buttons, signup forms,
  newsletter blocks, pricing prompts, modals/pop-ups.
- **Access:** Open / free.
- **Format:** Curated CTA examples by company in a grid.
- **Retrieval tip:** **Select by Industry** + **Select by mode** dropdowns, then narrow by
  content type (Button, Form, Newsletter, Pricing/Subscription, Modal/Pop-up).

## 6. 60fps.design
**URL:** https://60fps.design/ · **Category:** Motion
- **Best for:** Micro-interaction / animation inspiration from best-in-class apps -
  ~1,970 "Shots" of delightful UI motion.
- **Access:** Open / free.
- **Format:** Short animation clips ("Shots"); plus Apps (464), App Sites (75), Motion (25),
  Mockups, Learning, Storyboards.
- **Retrieval tip:** Filter by 89+ behavior tags - **Button, Drag, Loading, Scroll, Swipe,
  Zoom, 3D, AI** - to find a specific interaction rather than a whole app.

## 7. Rebrand Gallery
**URL:** https://www.rebrand.gallery/ · **Category:** Branding
- **Best for:** Brand identity / rebrand inspiration - new design systems, identity
  launches, reveal videos (Schweppes, Netflix, Walmart, Etsy…).
- **Access:** Freemium. Browse without account; free signup to keep browsing; Pro tier.
- **Format:** Logo/identity grid → per-rebrand case-study pages; some reveal videos.
- **Retrieval tip:** Explore **Intros** and **Bentos** sections for different cuts; click
  through the featured grid for full identity case studies.

## 8. The Component Gallery
**URL:** https://component.gallery/ · **Category:** Components
- **Best for:** Cross-referencing how the world's design systems build a given component -
  60 components across 95 design systems, 2,676 examples. Great for naming, structure, and
  behavior decisions, not just looks. *(Homepage returns 403 to bots; open in a browser.)*
- **Access:** Open / free.
- **Format:** Per-component pages aggregating screenshots, descriptions, and links into
  source design systems' docs (many React-based). Points to implementations, not a code dump.
- **Retrieval tip:** Browse by **component** (`/components/`) or **design system**
  (`/design-systems/`). Killer feature: **alias/naming reference** (Accordion = Collapse =
  Disclosure = Expander) to align terminology. Search via Pagefind.

## 9. Hugeicons
**URL:** https://hugeicons.com/ · **Category:** Icons
- **Best for:** Large, consistent icon set for product UI - 54,000+ icons in 9 styles
  (Stroke, Twotone, Duotone, Solid, Bulk × rounded/standard/sharp).
- **Access:** Freemium. Free tier (free icons + free Figma plugin); Pro for full library.
- **Format:** SVG + packages for React, React Native, Vue, Angular, Svelte, Flutter,
  WordPress, VS Code; icon font via CDN; Figma/Sketch/Illustrator support.
- **Retrieval tip:** Browse by style + keyword. Use the **Figma plugin** and **npm
  package** rather than copying individual SVGs for a real project.

## 10. Mobbin
**URL:** https://mobbin.com/ · **Category:** Mobile/App
- **Best for:** Real mobile + web app screens and end-to-end user flows from shipped apps.
- **Access:** Login required - **use an MCP server if you have one connected; otherwise browse the site.**
- **Tools (optional MCP):** screen, flow and section search.
- **Retrieval tip:** Query by app name or pattern (e.g. "onboarding", "paywall",
  "settings"). `search_flows` for multi-step journeys; `search_sections` for a single
  pattern across apps.

## 11. Collected
**URL:** https://collected.li/ · **Category:** Full Sites
- **Best for:** Serendipitous discovery of beautiful complete websites - a pool of 5,260+
  hand-picked designs (curated by Berlin designer Jonas Pelzer).
- **Access:** Open / free. No login.
- **Format:** Screenshot thumbnail cards → live site links.
- **Retrieval tip:** **No filters** - the gimmick is the **Shuffle**: it shows 8 random
  sites per visit. Reach for it when you want fresh, unbiased aesthetic input, not a
  targeted archetype. (Use Saaspo/Navbar/CTA when you need a *specific* thing.)

## 12. Site of Sites
**URL:** https://siteofsites.co/ · **Category:** Full Sites
- **Best for:** Filterable archive of exemplary full websites - 562+ sites, strong on
  multi-axis narrowing.
- **Access:** Open / free. No login. Community submissions + curation.
- **Format:** Thumbnail → Site of Sites profile page + live link.
- **Retrieval tip:** Four filter axes - **Industry** (design, photography, fashion, music…),
  **Type** (portfolio, e-commerce, landing), **Style** (minimal, experimental, colorful,
  retro), **Platform** (Webflow, Wix, Framer, Custom Code). Also has a glossary, agency
  directory, and blog. Best full-site source when you want to filter by *build platform*.

## 13. Unmatched Style
**URL:** https://unmatchedstyle.com/ · **Category:** Full Sites
- **Best for:** Long-running CSS/web-design gallery with editorial depth - Site-of-the-Day
  showcases plus written design-trend articles (glassmorphism, brutalism, monochrome
  minimalism).
- **Access:** Open / free. No login. Optional weekly newsletter (Beehiiv).
- **Format:** Screenshot thumbnails + live links; long-form trend articles with imagery;
  a **RADAR** section of curated links.
- **Retrieval tip:** Use the **articles** for *why* a trend works (not just a thumbnail),
  and the gallery for current Site-of-the-Day picks. Editorial angle distinguishes it from
  pure thumbnail walls.

## 14. Recent (formerly Godly)
**URL:** https://recent.design/ · **Category:** Full Sites (broad)
- **Best for:** A daily-updated cut of the best recent design on the Internet - websites
  plus branding, illustration, motion, 3D, and print, by the team behind **Godly**.
- **Access:** Open / free. No login. (Newsletter digest available.)
- **Format:** Screenshot/preview cards → live links; sortable feed.
- **Retrieval tip:** **`godly.website` now 301-redirects here** - same curators, broader
  scope. Browse by tab: **All · Best of X · Websites · OG Images · App Screenshots ·
  App Icons**. The **OG Images** and **App Store Screenshots** tabs are the standout -
  niche surfaces few other galleries cover.

## 15. Design Spells
**URL:** https://designspells.com/ · **Category:** Motion / Delight
- **Best for:** "Design details that feel like magic" - a catalog of specific delightful
  micro-interactions and details across mobile *and* desktop, each with a written
  explanation of the spell.
- **Access:** Open / free. No login. Optional newsletter; RSS feed (`/feed`).
- **Format:** Short clips / captioned detail cards, tag-filtered.
- **Retrieval tip:** Filter by tag - **Mobile, Desktop, Interaction, Easter egg,
  Skeuomorphic, Animation, Motion, Transition, Confetti, 404, Dynamic island, Button, 3D,
  Apple**. Complements **60fps.design**: 60fps shows the motion, Design Spells explains the
  *idea* behind a single delightful touch. Reach here for "what's a clever detail for X".

## 16. Refero
**URL:** https://refero.design/ · **Category:** Mobile/App + Web product UI
- **Best for:** Design *research* over real shipped product interfaces - screens, flows,
  and patterns, deeply indexed. Closest web-focused complement to Mobbin.
- **Access:** **Freemium + login** (Google/email; paid tiers - see `/pricing`). Has an
  **MCP server** at `https://api.refero.design/mcp` (docs: https://doc.refero.design/mcp/getting-started) to feed an agent real interfaces.
- **Format:** Screenshot library of product screens + multi-step flow captures.
- **Retrieval tip:** Five indexes - **Page Types** (Dashboard, Paywall, Log In, 404…),
  **Flows** (onboarding, subscribing, booking, money transfer…), **UX Patterns**
  (testimonials, filter/sorting, billing, dark mode…), **UI Elements** (modal, table, tabs,
  sidebar…), and **Sites** by industry. Killer feature: **filter pages by font** (e.g. all
  pages using Inter / SF / Helvetica Neue) - unique among these sources. If you want
  agent-native access to real interfaces, wire up its MCP rather than scraping.

## 17. Lucide
**URL:** https://lucide.dev/ · **Category:** Icons
- **Best for:** The default UI icon set - 1,600+ clean 24px stroke icons, community fork
  of Feather. It's what **shadcn/ui ships with**, so it's the usual baseline; reach elsewhere only when Lucide lacks the glyph or the style.
- **Access:** Free, open source (ISC). No login.
- **Format:** SVG + first-party packages for React (`lucide-react`), Vue, Svelte, Solid,
  Preact, Angular, React Native, Flutter; icon font; Figma plugin.
- **Retrieval tip:** Search on lucide.dev, then import by name from `lucide-react` -
  tree-shakeable, `size`/`color`/`strokeWidth` props. Keep stroke width consistent
  app-wide (default 2; 1.5 reads lighter/more premium).

## 18. Reicon
**URL:** https://reicon.dev/ · **Category:** Icons
- **Best for:** A second free set alongside Lucide - 2,700+ handcrafted pixel-perfect
  icons in **two weights (Outline & Filled)**, useful when you want a filled variant
  Lucide doesn't offer. Companion **brands.reicon.dev** has 3,400+ brand/company logos.
- **Access:** Free, open source (MIT). No login. GitHub: `dqev/reicon`.
- **Format:** SVG + `reicon-react` npm package (tree-shakeable, TypeScript,
  `size`/`color`/`weight` props); Vue, Svelte, Figma support.
- **Retrieval tip:** Browse/search on reicon.dev with live preview. Use the `weight`
  prop to swap Outline ↔ Filled on the same component. For brand logos, go straight to
  brands.reicon.dev instead of hunting SVGs.
